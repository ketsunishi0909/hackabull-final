# HackaBull 2026 Website

Official website implementation for **HackaBull 2026**, USF's student hackathon experience.

## Overview

This repository contains the public-facing event website for HackaBull 2026. It presents event information, tracks, sponsors, registration links, a photo gallery, and frequently asked questions in a responsive single-page experience.

## Highlights

- Responsive event landing page
- Interactive 3D-style track carousel
- Auto-rotating event gallery
- Sponsor grid and scrolling sponsor ticker
- FAQ accordion
- Registration, Discord, Instagram, LinkedIn, and MLH links
- Custom HackaBull visual system using HTML, CSS, and vanilla JavaScript

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts / HK Modular

## Running Locally

No build step is required.

```bash
git clone https://github.com/ketsunishi0909/hackabull-final.git
cd hackabull-final
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
